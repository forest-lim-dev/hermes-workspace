# 리서치 방법론

## 1. 콘텐츠별 추출 항목

각 영상/글/X 스레드에서 아래 항목을 추출합니다.

- 출처명 / URL / 제목 / 게시일
- 자산군: 국내주식, 미국주식, 코인, 공통
- 전략 유형: 돌파, 눌림목, 갭, 모멘텀, VWAP/이평, 거래량, 리스크관리, 심리/운영
- 매수 조건
- 매도/익절 조건
- 손절 조건
- 진입 금지 조건
- 시장/종목 필터
- 시간대 조건
- 포지션 사이징/분할 여부
- 백테스트 가능 여부
- 구현에 필요한 데이터
- 모호한 부분 / 추가 확인 필요

## 2. 백테스트 가능성 분류

### A. Backtestable
정량 조건이 충분히 명확하거나, 합리적 파라미터화가 가능한 경우.

예:
- 전고점 돌파 + 거래량 N배 + 손절 -X%
- VWAP 회복 후 첫 눌림 진입
- ORB(Opening Range Breakout)

### B. Needs Translation
전략 방향은 있으나 표현이 질적/주관적이라 정량화가 필요한 경우.

예:
- “강한 종목만 매수”
- “매물대가 얇을 때 진입”
- “차트가 예쁠 때”

### C. Non-backtestable Insight
직접적인 룰화는 어렵지만 운용/리스크/심리/종목선정에 유용한 경우.

예:
- 손실 후 오버트레이딩 금지
- 특정 뉴스 테마 추적 방식
- 장중 집중 시간대 관리

## 3. 전략 파일 작성 원칙

전략 후보 파일은 아래 순서를 따릅니다.

1. 한 줄 요약
2. 원천 콘텐츠 근거
3. 전략 논리
4. 룰 초안
5. 백테스트 명세 초안
6. 필요한 데이터
7. 모호성/해석 리스크
8. 반대 시나리오
