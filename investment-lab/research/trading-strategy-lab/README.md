# 주식·코인 단타 트레이딩 연구소

이 저장소는 유튜브/블로그/X 등 공개 콘텐츠에서 **단타매매전략으로 검증 가능한 아이디어**를 추출·정리하기 위한 리서치 작업 공간입니다.

## 작업 위치

- 로컬 경로: `/Users/jiuklim/trading-strategy-research-lab`
- Git: 로컬 저장소 초기화 완료
- GitHub 원격 저장소: GitHub CLI 미로그인 상태라 아직 연결 전입니다. `gh auth login` 후 원격 생성/푸시 가능합니다.

## 핵심 원칙

1. 현재 보유 데이터/기존 백테스트 구현 제약은 전략 리서치 단계에서 배제합니다.
2. 콘텐츠에서 나온 내용을 그대로 요약하는 데 그치지 않고, 백테스트 가능한 규칙으로 번역합니다.
3. 매수/매도/손절/포지션관리/필터/시장조건을 분리해서 기록합니다.
4. 백테스트 가능 여부를 명확히 구분합니다.
5. 전략 단위로 파일을 나누고, AI가 구현 가능한 스펙으로 정리합니다.

## 폴더 구조

- `00_admin/`: 범위, 진행 계획, 분류 기준
- `01_sources/`: 원천 콘텐츠별 메모와 추출 결과
- `02_strategy_candidates/backtestable/`: 백테스트 가능한 전략 후보
- `02_strategy_candidates/needs_translation/`: 아이디어는 있으나 규칙화가 더 필요한 후보
- `02_strategy_candidates/non_backtestable_insights/`: 매매에 유용하지만 직접 백테스트가 어려운 통찰
- `03_synthesis/`: 채널/트레이더별 종합, 공통 패턴
- `04_backtest_specs/`: 나중에 백테스트 코드로 옮기기 위한 명세
- `05_daily_logs/`: 일별 작업 로그
- `scripts/`: 수집/정리 보조 스크립트
